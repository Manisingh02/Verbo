# Verbo

### Purpose

Learning a new language can be challenging, especially when it comes to remembering vocabulary and applying it in everyday situations. Traditional language learning methods often lack personalization and real world interaction. Verbo addresses these challenges by combining artificial intelligence, interactive learning, and camera based recognition to help users build vocabulary and improve language retention.

### Features

Verbo is an AI powered mobile language learning application designed to make learning more interactive and personalized. Key features include:

- **Camera-Based Recognition**: Identify objects and recognize text using Google ML Kit and Hugging Face Florence-2 computer vision integrations.
- **Interactive Learning**: Practice vocabulary through flashcards, quizzes, and interactive lessons.
- **Personalized Learning**: Use adaptive learning algorithms and XGBoost-based recall predictions to tailor vocabulary review to individual performance.
- **Progress Tracking**: Monitor learning progress, quiz performance, and vocabulary development.
- **User Authentication**: Securely manage user accounts and learning data using Firebase Authentication and Firestore.
